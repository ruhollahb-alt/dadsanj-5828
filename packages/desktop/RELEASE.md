# انتشار دسکتاپ دادسنج

## ساخت نصب‌کننده

```bash
cd packages/desktop
bun run dist:win          # Windows x64 (NSIS)
# یا برای هر سه سکو: bun run dist
```

خروجی در `release/<version>/` ساخته می‌شود. نسخه از `packages/desktop/package.json` خوانده
می‌شود و همان مقدار در پانویس برنامه و گزارش چاپی/اکسل نمایش داده می‌شود.

## اثر انگشت فایل انتشار

```bash
bun run checksum "release/1.2.0/DadSanj-Windows-1.2.0-Setup.exe"
# فایل کنار نصب‌کننده: ...Setup.exe.sha256
```

فایل `.sha256` را همراه نصب‌کننده منتشر کنید تا کاربر بتواند سالم‌بودن دانلود را بررسی کند.

## امضای کد (نیازمند گواهی)

electron-builder این متغیرهای محیطی را به‌صورت خودکار می‌خواند؛ مقدارشان را در CI یا
ماشین انتشار تنظیم کنید و در مخزن قرار ندهید:

- Windows: `CSC_LINK` (مسیر یا base64 فایل PFX) و `CSC_KEY_PASSWORD`
- macOS: `CSC_LINK`/`CSC_KEY_PASSWORD` یا `APPLE_ID`، `APPLE_APP_SPECIFIC_PASSWORD` و `APPLE_TEAM_ID`

بدون گواهی معتبر، ویندوز برای نصب‌کننده هشدار SmartScreen نشان می‌دهد. این مرحله در
محیط توسعهٔ فعلی قابل اجرا نیست و به گواهی امضای کد نیاز دارد.

## به‌روزرسانی خودکار (فعال‌نشده)

auto-update نیازمند سه چیز است که هنوز در مخزن نیست:

1. کانال انتشار (GitHub Releases یا یک URL ساده) و شمارهٔ نسخهٔ همیشه افزایشی،
2. نصب و پیکربندی `electron-updater` با provider مشخص،
3. امضای بسته‌ها تا به‌روزرسانی بدون هشدار پذیرفته شود.

تا فراهم‌شدن این‌ها، انتشار به‌صورت دستی و با checksum انجام می‌شود؛ نسخهٔ فعلی
به‌روزرسانی خودکار را ادعا نمی‌کند.
